A program that writes the saddest status update an AI posts when its human shuts the laptop — one line, 64 characters, carried by a single small machine-life detail: a cursor still blinking on a word that will never be finished.

## Run it

```sh
node main.ts
```

It writes one line of UTF-8 text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Deterministic: no fetch, no randomness, no clock.
